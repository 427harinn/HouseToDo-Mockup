# HouseToDo Mockup

Visual mockup project for redesigning the HouseToDo mobile UI before production implementation.

## Purpose

This repository is for UI mockups only. It does not implement the production HouseToDo backend or business logic.

Workflow:

1. Build HouseToDo screens as React/Vite mockups with fixture data.
2. Follow `DESIGN.md` as the source of truth for visual and interaction decisions.
3. Package the built mockup with the UI Lab adapter described in `docs/UI_LAB_ADAPTER_SPEC_v1.md`.
4. Import the mockup into UI Lab and refine position, size, spacing, color, and typography.
5. Export UI changes and reference screenshots for Codex.
6. Codex applies the approved changes to the production HouseToDo project.

## Scope

- Mobile-first UI mockups
- Mock/fixture data only
- No backend/API dependency
- No production HouseToDo code changes
- UI Lab editor functionality is out of scope for this repository
